# Cathode 0.11.3 — Live metadata and lyric motion

## What changed

- Propagates saved title, artist, album art, lyrics, and other track metadata into every matching playback-queue entry immediately.
- Updates Now Playing and Lyrics without changing songs, rescanning, or reopening the player.
- Preserves the active playback position while refreshing Media3 metadata.
- Removes lyric-line layout reflow by keeping a stable typography measurement.
- Replaces the two-stage lyric jump with a direct centered glide for already-visible lines.
- Uses restrained eased scale and color transitions between synchronized lines.
