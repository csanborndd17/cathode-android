# Cathode 0.9.2

## What changed

- Moves saved playlist-migration sessions from SharedPreferences into transactional SQLite tables.
- Migrates the 0.9.0/0.9.1 saved conversion session into SQLite on first launch.
- Encrypts Spotify access/refresh tokens and the YouTube API key with AES-GCM keys held by Android Keystore.
- Migrates existing plaintext provider credentials and removes the old plaintext values.
- Masks the YouTube API-key field and does not repopulate the decrypted key into the interface.
- Disconnect/remove actions delete encrypted credentials.
- Adds privacy, third-party notice, installation/update, and production-signing documentation.

## Storage migration

Database version increases from 2 to 3. Existing favorites, playlists, history, and Transmission Log tables are preserved. New `import_sessions` and `import_session_tracks` tables store the latest migration session.

## Desktop parity

Desktop should use its operating system credential vault for provider tokens and a transactional local database for large import sessions.
