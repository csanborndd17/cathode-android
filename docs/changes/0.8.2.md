# Cathode 0.8.2

## Changed

- Disabled edge-swipe opening for the profile drawer. The drawer now opens only from the profile picture and still closes through its controls or Android back navigation.
- Added track multi-selection by long-pressing a song, then tapping additional songs.
- Added bulk actions to add selected songs to an existing playlist or create a new playlist containing them.
- Added permanent device-file deletion through Android's system MediaStore confirmation dialog.
- Enabled extractor fallback seeking and exposed unseekable-file status for malformed or incompletely indexed audio containers.
- Clarified that the sleep timer pauses background playback after the selected interval.

## Storage behavior

Deleting selected tracks uses Android's system-owned confirmation UI on Android 11 and newer. Cathode cannot silently remove files. After approval, MediaStore is rescanned and deleted tracks disappear from the library.

## FLAC seeking

FLAC sample rate and bit depth do not determine seekability. Files without a valid seek table, duration, or decodable frame index may play sequentially while remaining unseekable. Cathode enables Media3 fallback seeking where supported and reports when the active item still has no usable seek map.
