# Cathode 0.10.0 — Advanced library organization, part 1

## What changed

- Adds persistent custom artwork to local playlists.
- Adds playlist renaming without recreating the playlist.
- Adds explicit move-up and move-down controls for playlist tracks.
- Normalizes stored positions after a track is removed.
- Preserves existing playlists through the database version 4 migration.

## Why

Cathode's original playlists could collect tracks but could not be curated as durable collections. This migration establishes the storage model needed by the remaining organization work without changing track identities or source files.

## Remaining 0.10 work

- Genres and aliases.
- Hidden tracks and duplicate detection.
- Rule-based smart playlists.
- Batch metadata editing and metadata history follow in the next development group.

## Desktop parity

Desktop playlists should preserve the same stable track-key order and optional custom-artwork URI semantics, while translating the artwork reference to a desktop-managed file.
