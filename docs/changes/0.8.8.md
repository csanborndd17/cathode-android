# Cathode 0.8.8

- Moves soft-transition controls from Now Playing to Advanced Settings.
- Removes quality badges and quality filters from the everyday Library UI. Codec and spectral details remain available in track diagnostics.
- Moves lossless-integrity analysis to Advanced Settings with separate incremental and reset/reanalyze actions.
- Adds an on-device diagnostics log for crashes, playback failures, download failures, and library scan failures.
- Clarifies that spectral analysis can only flag a suspected lossy transcode; it cannot prove a file's recording lineage.
- Detects playlist URLs in the converter and explains when an authorized provider connection is required instead of silently ignoring the link.

## Desktop parity notes

Desktop should keep audio-integrity information in a diagnostics/details surface, not as a definitive per-track quality badge. Match the two analysis actions (new files and reset/reanalyze) and use a local bounded diagnostics log.
