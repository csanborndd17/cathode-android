# Cathode 0.12.1 — Live lyrics and playback detail polish

## What changed

- Adds a playback-state metadata override keyed by stable track ID so newly saved lyrics, artwork, titles, and artists appear immediately for the active item.
- Adds Find and save / Find replacement actions directly to the Now Playing Lyrics screen.
- Adds a sequential batch lookup for every library track missing lyrics.
- Shows batch progress and retains a list of tracks that could not be matched.
- Adds a dark drop shadow to lyrics for contrast over bright artwork.
- Adds previous, play/pause, and next controls to the queue's Now Playing card.
- Hides Signal Details on initial entry and reveals them with an upward fade after the listener scrolls down.
- Centers Signal Details and moves the Local playback label into that panel.

## Batch behavior

Batch lookup is intentionally sequential to limit memory use and avoid flooding the anonymous lyrics service. Successful matches are persisted immediately; closing the Lyrics screen cancels its active batch coroutine. Tracks already containing lyrics are skipped.
