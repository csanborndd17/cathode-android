# Cathode 0.8.1 — Library and playback reliability

## What changed

- Added live MediaStore observation and debounced rescanning.
- Completed downloads are explicitly submitted to Android’s media scanner.
- Discover shows download progress, cancellation, and persistent failure reasons.
- A malformed MediaStore row is isolated instead of aborting the entire scan.
- Zero-duration/unfinished metadata records can enter the library safely.
- Added a background-safe sleep timer.
- Added playback error reporting and automatic continuation past unavailable queue items.
- Explicitly keeps gapless progression enabled when Media3 and the source format support it.

## Why

Local files change outside Cathode, and downloads or damaged metadata must not require an app restart or destroy the library experience. Playback should also recover when a queued file disappears.

## Android implementation

- A ContentObserver watches the external audio collection and coalesces rapid changes.
- DownloadManager state is polled only while Discover is composed.
- The playback service enforces sleep expiry even when Now Playing is closed.
- Existing queue, position, shuffle, repeat, audio-focus, and noisy-route restoration remain authoritative.

## Desktop parity instruction

- Replace MediaStore observation with a filesystem watcher.
- Use the platform download subsystem or a constrained HTTPS client with equivalent progress and cancellation.
- Persist queue and timer state in the desktop database.
- Skip unreadable files without discarding the remaining queue.

## Data compatibility

No library database migration is required. Playback preferences gain an optional sleep-end timestamp.

## Verification

- Run unit tests, parity validation, and debug APK assembly.
- Manually verify MediaStore callbacks, download notifications, timer expiry, and missing-file recovery on the OnePlus 13R.

## Remaining transition work

True overlapping crossfade requires two synchronized decoder/player pipelines and remains queued. ReplayGain remains planned until Cathode has a verified tag reader for R128 and ReplayGain metadata; volume guessing is not an acceptable substitute.
