# Cathode 0.8.3

## Changed

- Increased mini-player artwork visibility while retaining restrained blur and gradient treatment.
- Completed downloads now remain in Discover as `INSTALLED` until explicitly dismissed.
- Long album, artist, folder, and playlist detail titles remain on one line and use Cathode's marquee loop.
- Sleep timers now accept custom seconds, minutes, or hours.
- Custom duration presets can be saved and removed.
- Sleep timers can target a specific time of day; a time that already passed is scheduled for the following day.
