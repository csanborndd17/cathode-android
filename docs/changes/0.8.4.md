# Cathode 0.8.4

## Playlist conversion foundation

- Added a credential-free playlist converter to Discover.
- Accepts exported track lists and common `Artist - Title` line formats.
- Removes numbering, blank lines, duplicate searches, and pasted source URLs.
- Lets the listener choose a Discover source for each search.
- Copies the normalized query and opens the source without scraping or bypassing service access controls.

## Audio diagnostics

- Added per-track audio diagnostics under Track actions.
- Reports container MIME type, duration, sample rate, bit depth, bitrate, stream count, and file size when Android can read them.
- Flags missing duration metadata and explains the remaining FLAC seek-table limitation.

## Scope

Automatic Spotify and YouTube playlist resolution still requires their authorized APIs. Lossless FLAC remuxing is not included yet because it requires a bundled native codec toolchain and explicit file-replacement handling.
