# Cathode 0.8.6

## Lossless integrity

- Classifies local tracks as Lossless, Hi-Res Lossless, Lossy, or Unknown.
- Reads FLAC STREAMINFO directly to verify sample rate and bit depth.
- Hi-Res currently means a verified lossless FLAC above 16-bit or 48 kHz.
- Adds quality badges to Library rows, Now Playing, and Audio Diagnostics.
- Adds Library filters for each quality classification.
- Verifies the actual decoded audio MIME type after a Cathode-managed download instead of trusting its filename.
- Keeps the verified result on the Installed download card.
- Sends an Android notification when a downloaded file resolves to a lossy codec despite its filename or listing.

## Color picker

- Replaces manual hexadecimal entry with an interactive RGB color picker, live preview, numeric channel values, apply action, and preset reset.

## Accuracy boundary

Codec verification can prove whether the stored encoding is lossless. It cannot prove that a FLAC was never transcoded from a lossy master. `Suspected transcode` remains reserved for a future optional spectral scan and is not assigned from metadata guesses.
