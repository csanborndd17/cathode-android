# Cathode 0.12.2 — Lyrics timing adjustment

## What changed

- Displays the synchronized timestamp above every timed lyric line.
- Adds global −1 second and +1 second controls to the Lyrics screen.
- Shifts every LRC timestamp together and saves the adjusted lyrics immediately.
- Clamps timestamps at zero when shifting backward.
- Keeps lyric seeking, live highlighting, manual scrolling, and recenter behavior intact.

This is intended for LRC files whose synchronization is consistently early or late. It changes Cathode's local lyrics override and never rewrites the audio file.
