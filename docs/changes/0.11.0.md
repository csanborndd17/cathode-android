# Cathode 0.11.0 — Metadata and portability

## What changed

- Adds a layout-resolution override in Settings: Compact, Auto, Large, and Reset to detected default.
- Auto preserves Android's detected density; Cathode does not claim to change the physical display resolution.
- Adds batch artist, album, and tag editing through Library multi-selection.
- Adds an adjustable square artwork crop with zoom and horizontal/vertical positioning.
- Saves cropped artwork into Cathode's private storage instead of modifying the selected source image.
- Imports plain text and timestamped `.lrc` files directly into a track's local lyrics override.
- Exports and restores a versioned JSON backup through Android's document picker.

## Backup contents

The backup contains Cathode settings, metadata and lyric overrides, favorites, manual and smart playlists, playlist ordering, listening history, Transmission Log data, and playback-session state. Spotify tokens and YouTube API credentials are intentionally excluded because they are protected by Android Keystore and should be reconnected per installation.

External music files are not copied into the backup. Cathode-generated cropped covers are embedded in the backup. Artwork selected directly from another document provider remains subject to that provider's Android access permissions.

## Frozen remaining roadmap

- Pin tracks and playlists to Home.
- Multiple Now Playing layouts.
- Waveform style and color choices.
- User-created EQ presets.
- Backup/desktop expansion remains deferred. Testing and final release hardening remain last.
