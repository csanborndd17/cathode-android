# Cathode 0.8.9

- Adds official Spotify OAuth authorization-code authentication with PKCE.
- Opens Spotify sign-in in the user's external browser; Cathode never receives the Spotify password.
- Uses a temporary loopback callback and stores OAuth tokens locally on the device.
- Adds Spotify Client ID, connect, reconnect, and disconnect controls to Advanced Settings.
- Resolves pasted Spotify playlist URLs into artist/title rows automatically.
- Handles paginated playlists and refreshes expired access tokens.
- Does not download or stream Spotify audio and does not scrape Spotify webpages.

## Desktop parity notes

Use the same OAuth authorization-code flow with PKCE and loopback redirect on desktop. Share playlist parsing behavior and provider error messages, but do not sync OAuth tokens between devices.
