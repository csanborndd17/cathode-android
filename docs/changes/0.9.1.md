# Cathode 0.9.1

## What changed

- Adds official YouTube Data API import for public YouTube and YouTube Music playlists.
- Adds YouTube API-key setup, save, and removal controls under Advanced Settings.
- Paginates large YouTube playlists at 50 entries per request and feeds results into the existing lazy search queue.
- Extracts artist/title pairs from common video-title formats and uses channel names as a fallback.
- Skips deleted and private placeholder videos.
- Adds JVM unit tests for playlist-ID extraction, music-title cleanup, and channel fallback.
- Adds environment-driven release signing and release-build documentation without storing a signing key in the repository.

## Constraints

- API-key access covers public playlists. Private YouTube playlists require Google OAuth and remain planned.
- Video titles are uploader-provided; artist/title separation is heuristic when structured music metadata is unavailable.

## Desktop parity

Desktop should share playlist-ID extraction and title normalization behavior. API credentials remain local per installation.
