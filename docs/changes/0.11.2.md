# Cathode 0.11.2 — Lyrics presentation polish

## What changed

- Adds a fade-and-rise transition between Now Playing and Lyrics.
- Centers the active synchronized lyric in the viewport.
- Enlarges and center-aligns lyric typography for a karaoke-style presentation.
- Animates scale and color as playback advances between lyric lines.
- Stops automatic lyric following as soon as the listener manually scrolls.
- Adds a floating recenter control that returns to the current lyric and resumes live following.
- Keeps tapping a timed lyric as a seek action.

## Behavior

Live following is enabled whenever Lyrics opens. Manual scrolling disables it so Cathode never fights the listener's position. The recenter control is only visible while live following is paused.
