# Cathode 0.10.1 — Smart collections and queue clarity

## What changed

- Forces the Android window, launch background, status bar, navigation bar, and unused display area to true black.
- Uses adaptive Home columns and horizontally scrollable Now Playing actions instead of assuming one phone width.
- Adds a review-only Duplicates category based on normalized artist/title and a two-second duration tolerance.
- Adds editable smart playlists for favorites, recent tracks, most-played tracks, tags, artists, albums, and verified lossless audio.
- Reworks Queue into a dedicated Now Playing card and numbered Up Next list.
- Moves queue ordering/removal actions into per-track menus and adds Move to next.

## Safety and accuracy

Duplicate detection identifies likely copies; it does not automatically delete files. Smart playlists are computed from the current library and listening state and do not duplicate audio files.

## Data migration

Database version 5 adds `smart_playlists`. Existing favorites, playlists, artwork, ordering, history, statistics, and import sessions are preserved.

## Frozen remaining roadmap

- Batch metadata editing, artwork cropping, LRC-file import, and data export/restore.
- Pin tracks and playlists to Home.
- Multiple Now Playing layouts, waveform style/color choices, and user-created EQ presets.
- Backup/desktop work is deferred. Testing and final release hardening remain last.
