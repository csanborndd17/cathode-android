# Cathode 0.9.0

## What changed

- Adds explicit Spotify connection instructions that distinguish the Redirect URI, Client ID, and Client Secret.
- Adds **Search all** for parsed playlists.
- Opens the selected Discover source directly on the current track's search results instead of copying text to the clipboard.
- Adds an in-browser search-session bar with Previous, Queue, Skip, Next, and Finish controls.
- Adds a lazily rendered queue that can jump directly to any track and shows searched/skipped state.
- Replaces eager playlist-row composition with lazy rendering so multi-thousand-track imports do not create every row at once.
- Persists resolved Spotify track/artist rows, completed searches, skipped searches, and the selected source when saving a session.
- Updates the platform parity ledger to reflect implemented Spotify import, ReplayGain, and synchronized lyrics.

## Why

Playlist migration previously still required manual paste operations and became sluggish because every track row was composed simultaneously. The new workflow retains user choice over each result and download while removing repetitive search entry and bounding UI work to visible rows.

## Desktop parity

Desktop should use the same provider-neutral search-session state: source, ordered lightweight track records, current index, searched/skipped sets, and persisted resume data. Provider URLs and browser integration remain platform-specific.
