# Cathode 0.8.5

## ReplayGain

- Parses FLAC Vorbis comments for `REPLAYGAIN_TRACK_GAIN` and `R128_TRACK_GAIN`.
- Exposes detected gain in Audio Diagnostics and Now Playing.
- Adds opt-in playback normalization capped at unity gain to prevent digital clipping.
- Files without declared gain remain unchanged.

## Local lyrics

- Adds locally stored lyrics to Cathode metadata overrides.
- Supports plain text and timestamped LRC lines.
- Adds a Now Playing lyrics screen with position-based highlighting for LRC lyrics.
- Lyrics remain local and do not modify the source audio file.

## Playlist conversion

- Adds editable conversion queues through per-track removal.
- Tracks which searches have been opened.
- Saves and resumes conversion drafts, selected source, and progress.

## Transitions and FLAC diagnostics

- Adds a configurable 1–12 second soft fade around track boundaries.
- Reports whether FLAC files contain a SEEKTABLE metadata block.

The soft fade is not an overlapping two-decoder crossfade. Native lossless FLAC rewriting is also not performed in this release; Cathode will not pretend to repair a file without a verified remux pipeline and Android replacement confirmation.
