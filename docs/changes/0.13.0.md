# Cathode 0.13.0

## What changed

- Fixed LRC timing adjustment so every timestamp moves by one shared offset without compressing the spacing between lyric lines.
- Moved timestamp adjustment into the metadata editor and separated lyric lookup from saving.
- Added Library-level batch lyric lookup with progress and an unmatched-track list.
- Added batch custom artwork for multi-selected tracks and fixed artwork selection being interrupted by an automatic activity-resume scan.
- Restored song grid view, persisted two-to-five-column density, added pinch-to-resize, and consolidated Library controls into an options menu.
- Replaced the Home lossless shortcut with Artists and added a subdued scroll reveal for lower Home content.
- Extended artwork theming behind the system bars while preserving safe content insets.
- Changed Discover's primary Monochrome endpoint to `monochrome.samidy.com`, retained official fallbacks, and added an external-browser escape hatch.
- Kept only account-free source cards: Monochrome, Internet Archive, and Wikimedia Commons. Source availability and individual file licensing still vary.

## Why

This release fixes metadata workflows that were losing state, makes lyric synchronization predictable, reduces Library header clutter, and makes Discover resilient to an unavailable Monochrome domain.

## Desktop parity

Desktop should reproduce the non-destructive metadata model, batch artwork application, shared-offset LRC editing, adjustable grid density, and source-hub fallback behavior.
