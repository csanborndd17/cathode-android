# Cathode 0.8.10

- Changes Spotify OAuth from a dynamic loopback port to the fixed callback `http://127.0.0.1:43821/callback`.
- Matches Spotify Dashboard's current validation requirement that loopback redirect URIs include an explicit port.
- Updates the setup instructions shown in Advanced Settings.

## Desktop parity notes

Desktop may use a separate fixed loopback port, but its registered redirect URI must exactly match the port and path requested during authorization.
