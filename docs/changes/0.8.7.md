# Cathode 0.8.7

## Optional spectral integrity scan

- Adds a manual, cancellable whole-library lossless integrity scan.
- Decodes six spaced windows from each unscanned lossless track and applies a Hann-windowed FFT.
- Requires repeated high-frequency absence across the analyzed windows before assigning `Suspected transcode`.
- Quiet windows are excluded rather than treated as evidence.
- Stores the classification and estimated bandwidth in Cathode's local metadata cache.
- Previously analyzed files are skipped on later scans unless their stable file identity changes.
- Displays scan progress and cancellation controls in Library.
- Adds scan status and estimated bandwidth to Audio Diagnostics.
- Adds album-level Hi-Res, Lossless, Mixed/Lossy, Unknown, and Suspected Transcode summaries.

## Interpretation

`Suspected transcode` is probabilistic. Old recordings, deliberate filtering, low-bandwidth masters, and some acoustic sources can resemble lossy encoding. Codec classifications remain definitive; spectral classifications do not.
