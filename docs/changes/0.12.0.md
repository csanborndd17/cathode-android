# Cathode 0.12.0 — Waveform and Audio Lab customization

## What changed

- Adds four scrubber render styles: Bars, Mirror, Signal line, and Dots.
- Adds App accent, Cyan, Amber, Magenta, White, and Custom waveform colors.
- Reuses Cathode's full-spectrum gradient picker for custom waveform colors.
- Persists waveform appearance in Cathode settings and backups.
- Saves the current equalizer bands and bass boost as a named user preset.
- Applies, renames, replaces, and deletes user-created EQ presets.
- Keeps device-provided EQ presets alongside Cathode user presets.
- Safely applies only the supported band count if an audio route exposes a different equalizer layout.

## Scope

EQ availability still depends on Android providing an audio-effects session for the active output. Some Bluetooth or USB devices perform additional processing after Cathode's equalizer.

## Remaining personal-release work

- Continue using the cached stable debug signing key for install-over updates.
- Produce and verify each requested APK through GitHub Actions.
- No Play Store, AAB, desktop edition, formal test matrix, or permanent release-signing work is planned.
